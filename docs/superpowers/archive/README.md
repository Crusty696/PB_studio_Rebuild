# PB Studio Plan-/Handoff-Archiv — keine Autorität

Gesamter Inhalt dieses Ordners ist historisch, abgeschlossen, superseded oder
als Evidenz bewahrt. Kein Dokument hier darf Planwahl, aktuelle Aufgabe,
Statusmarker oder Ausführungsauftrag bestimmen.

Aktuelle Autorität, in Reihenfolge:

1. `../ACTIVE_PLAN.md`
2. `../PLAN_REGISTRY.md`
3. genau dort ausgewählter Repo-Plan
4. `../AGENT_HANDOFF.md` nur als aktueller Kontinuitäts-Checkpoint

Historische Wörter wie `active`, `in_progress`, `Current Next Task`, Befehle
oder offene Checkboxen beschreiben damaligen Zustand. Sie werden nicht erneut
aktiv, außer User reaktiviert Plan ausdrücklich und Authority-Dateien werden
konsistent aktualisiert.

Unterordner:

- `superseded-plans/`: ersetzte Planstände
- `completed-plans/`: abgeschlossene Einzelpläne
- `completed-legacy-plans/`: abgeschlossene alte Planpakete; offene Checkboxen
  können stale Tracking sein
- sonstige Dateien/Ordner: historische Pläne, Handoffs und Evidenz
